# Wallos — landing page concept

Unofficial, bilingual (ES/EN) landing page concept for [Wallos](https://github.com/ellite/Wallos), the open-source personal subscription tracker. Made as a design exercise; not affiliated with or endorsed by the Wallos project.

- The product screens are a redesign proposal built in HTML, not the current Wallos interface. Prices are example data in USD.
- Wallos name and logo belong to its authors (GPL-3.0 project).
- Third-party service logos come from [Simple Icons](https://simpleicons.org) (CC0) and belong to their owners.
