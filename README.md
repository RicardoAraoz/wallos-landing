# Wallos — landing page concept

Unofficial, bilingual (ES/EN) landing page concept for [Wallos](https://github.com/ellite/Wallos), the open-source personal subscription tracker. Made as a design exercise; not affiliated with or endorsed by the Wallos project.

Logo and screenshots in `img/` come from the [Wallos repository](https://github.com/ellite/Wallos) (GPL-3.0). Screenshots were only cropped.
